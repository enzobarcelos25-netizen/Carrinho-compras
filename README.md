# Carrinho de Compras

Aplicacao web de carrinho de compras desenvolvida com HTML, CSS e JavaScript.

## Objetivo

Praticar logica de programacao, manipulacao do DOM e calculos dinamicos simulando uma experiencia basica de e-commerce.

## Funcionalidades

- Adicionar produtos ao carrinho.
- Selecionar quantidade de itens.
- Calcular valor total automaticamente.
- Limpar o carrinho.
- Exibir itens adicionados na interface.

## Stack

- HTML5
- CSS3
- JavaScript

## Estrutura

```txt
Carrinho-compras/
  index.html
  style.css
  app.js
  assets/
```

## Como executar

Abra o arquivo `index.html` no navegador.

## Aprendizados praticados

- Manipulacao de eventos.
- Atualizacao dinamica de valores.
- Controle de listas no DOM.
- Organizacao de interface simples.
